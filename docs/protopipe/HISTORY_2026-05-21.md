## Production issues fixed today

### 1. Mongo E11000 on `protopipe_agent_runs`
- **Symptom:** `dup key: { siteId, idempotencyKey: null }`
- **Cause:** Legacy unique index; multiple runs without `Idempotency-Key` stored as `null`
- **Fix:** `d012be1` always assigns `type:uuid`; partial index in `00747eb`
- **Ops (if still broken):** Atlas mongosh — `$unset` null keys, `dropIndex("siteId_1_idempotencyKey_1")`, restart bagend

### 2. Claude API 404
- **Cause:** `claude-sonnet-4-20250514` deprecated/unavailable
- **Fix:** Default `claude-sonnet-4-6`; set `PROTOPIPE_CLAUDE_MODEL` on **server** `.env`

### 3. Article ideas client timeout
- **Cause:** Sting polled 60×500ms = 30s; Claude often slower; no server error
- **Fix (bagend):** Logging `agent run started/succeeded` + `durationMs`; expose `output` on succeeded runs (`d20a4a2`)
- **Fix (sting, local):** Poll 120×1s; use `run.output.ideas` when present

### 4. JSON parse failures from Claude
- `` ```json `` fences / missing closing fence → `Unrecognized token '\`'`
- Truncated JSON at 2048 tokens → `Expected ']'`
- **Fix (`aff4dcd`, `11e2b06`):** Fence strip, brace extraction, `repairTruncatedJson`, 4 ideas max, outline as string[], `max_tokens` 4096
- On parse failure: fallback keyword ideas; run still **succeeds**
