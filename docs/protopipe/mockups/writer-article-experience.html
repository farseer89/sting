How you get there today

  • Home nav: Content → Writer enters writer focus (hides left nav)
  • ProtopipeHomeWriterComponent embeds ProtopipeWriterComponent
  • Left tool rail + optional right inspector (Brief, SERP, Blog preview, etc.)
  • “Preview on site” is a separate takeover — not the default writing surface

Current limits

  • Canvas uses app UI fonts; centered H1/intro — not site .prose theme
  • Legacy sections: images in a detached “Images” panel below body
  • Block-layout posts: dashed app-protopipe-image-placeholder with always-visible URL/alt fields
  • Published order is H2 → image → body (renderArticleBlocks); editor order matches only for block layout
  • Blog preview HTML exists but lives in inspector / takeover, not inline

Target principles

  • One column, max-width 42rem — same as live blog
  • Site serif/sans + warm paper background from theme tokens
  • Figures are full-width in column; edit on hover/focus
  • Empty slots use subtle dashed frame (preview placeholder), not form chrome
  • SEO/meta/schedule stay in inspector — not on the article surface

Implementation sketch

  • Add .pw__canvas--article mode: import theme prose tokens (or iframe site CSS)
  • Replace app-protopipe-image-placeholder inline variant with figure + overlay editor
  • Migrate legacy section images into flow; drop always-visible media panel
  • Left-align intro; add meta line (date + draft badge)
  • Reuse renderBlogPreviewDocument styles on canvas, not only in sidebar
